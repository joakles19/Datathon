# Project Working Rules

## Chapter Delivery

When a planned chapter is complete and its relevant checks pass:

1. Review the diff and commit only the changes belonging to that chapter.
2. Create a Git commit using the repository's Lore commit format.
3. Push the commit to `origin/ai_david`.
4. Report the commit hash and pushed branch before moving to the next chapter.

Do not include unrelated user changes in the chapter commit. Never force-push; if the push is rejected, preserve the local work and report the blocker for resolution.
